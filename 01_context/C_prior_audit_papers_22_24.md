## 22번: "Auditing successor selection in software repository mining: Evidence from filtering AI-attributed commits" (JSEP, SMR-26-01286)

### 질문
저장소 마이닝에서 "AI 귀속 커밋을 제외한다"는 흔한 전처리가, 같은 계정·같은 기준 사건(앵커)에서 **후속 사건 집합만 바꿈으로써** 사건 기반 측정치를 얼마나 움직이는가.

### 고정 앵커 설계(28번이 그대로 가져갈 뼈대)
- 분석 단위: 계정. 앵커 = 계정의 기준 커밋(첫 트레일러 등). 모든 비교에서 앵커 집합 고정.
- 비교 셀 3개: **UU**(앵커·후속 모두 필터 없음) / **UA**(앵커 그대로, 후속만 AI 귀속 제외) / **AA**(앵커·후속 모두 제외). 보고값 예: UU −6.31pp / UA −0.09pp / AA +3.03pp, 짝지은 차이 +6.23pp [5.93, 6.53], 계정 3,687(선별 3,985).
- 용량-반응: 귀속 강도 5구간(0.38 → 20.46pp).
- 기대값 대조: "개수만 맞춘 무작위 제외"의 기대 이동(+10.47pp) 대비 관측이 약 40% 작음 → 선택이 무작위가 아님을 보임.
- 음성 대조: revert-only 집합(차이 0).
- 층별: 도구별(Claude +8.94 / Copilot +2.01 / Cursor +3.05 / Minor +3.08).
- 시뮬레이션: 500회 × 밀도·집중도·귀속확률 격자(60%에서 3.09~28.73pp).
- 구성 점검: 공통 패널 3,182, 같은 날짜 후속 제외 민감도, 대조 패널 3종 병렬 표.
- 서술: 사전등록 효과 검증 → **탐색적 측정 감사**로 재프레이밍한 뒤 데스크 통과(EMSE·SSCR·JNSM·JSS 리젹 뒤 JSEP). 초록 수치 축소, we → I.
- 참고문헌 18편으로 짧음. 윤리: IRB 판단 없이 사실만 기재. 데이터: 익명 zip(코드·테스트·집계·시뮬레이션) + 계정 수준 파생은 편집부 경유 요청 시.

### 28번으로의 매핑
| 22번 | 28번 |
|---|---|
| 계정 | 편집자(등록 계정, 봇 제외) |
| 앵커 커밋 | 첫 본문 편집(또는 첫 K=5편집) |
| 후속 커밋 집합 선택(AI 귀속 제외) | 되돌림으로 인정하는 후속 revision 선택(F0 전체 / F1 봇 제외 / F2 봇+도구 제외) |
| 측정치(사건 기반 변화율) | 코호트 되돌림 비율, 편집자 success rate, 되돌림→잔존 odds ratio |
| 귀속 강도 용량-반응 | 봇·도구 활동 밀도(위키×연도) 용량-반응 |
| revert-only 음성 대조 | 봇·도구가 없는 시기·위키(차이 0 기대) |
| 500회 시뮬레이션 | 봇 속도·밀도·되돌림 확률 격자 시뮬레이션 |
| 신규 요소 | **관찰 창 축**(24h / 7d / 최종)과 **정의 축**(identity revert vs mw-reverted 태그) |

## 24번: "Disclosure Is Not Use: Vendor Defaults and Marker Changes in AI-Attribution Traces on GitHub" (EMSE, EMSE-D-26-01378)
- 도구 기본값 변경(VS Code git.addAICoAuthor on/narrow/off 2026-04-22/04-29/05-06, aider 2025-06-27, Cursor 마커 변경)을 자연실험으로 삼은 ITS/RD-in-time. 등록 ITS d1 = 5.45(NW SE 0.67), 위약 최대 1.79, 대조 이동 ≤ 0.12.
- 28번에서 쓸 요소: **위약 컷(placebo cut)과 대조 시계열** 서술 방식, 편차 로그(#14~#38) 공개 관행, 검토 4회(내부 v1~v3 + 외부 Codex v5.1) 후 투고하는 절차.
- 28번에도 자연실험 축이 있다: 2011년 ClueBot NG 중단(Geiger & Halfaker 2013), 위키별 Huggle/Twinkle 도입·태그 도입 시점(mw-* 태그는 2018년 전후 도입). 이들을 창 민감도의 외생 변동으로 쓸 수 있다(확증이 아니라 보조 분석).
